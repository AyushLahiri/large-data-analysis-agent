How to organise your uploads
  1. Start with the main data file. A folder is created automatically, with no questionnaire yet.
  2. Add and tag the remaining files. Each upload opens a tagging window. Multiple files use Save and next.
  3. Choose Complete ingestion. Review any exact copies, answer the file questions, and save the folder.
  4. Add more folders or begin. Saving a form unlocks the next folder. Choose Ingest materials when all your folder forms are ready.

A related lookup or geographic dataset gets its own folder. Original uploads and your descriptions remain saved locally.
