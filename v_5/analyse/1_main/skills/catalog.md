# Analysis skills

- General analysis → read **general** for cross-tabs, descriptives, comparisons, distributions, outliers, or a bounded record preview. For example, ask how fuel type varies by region or what households typically spend each year.
- Hypothesis testing → read **tests** for a t-test or chi-square test. Example: Is there evidence that mean spending differs between urban and rural households?
- Cross-folder joins → read **cross_folder_joins** when the question needs records or summaries from different folders linked. Example: Compare two folders’ state-level statistics by matching their state names.
- Linear or logistic regression → planned reference for adjusted associations with continuous or binary outcomes. In this release, explain what variables and design details the model would need. The regression execution guide is pending.
