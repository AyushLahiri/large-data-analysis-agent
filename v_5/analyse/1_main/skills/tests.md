# t-tests and chi-square tests

- If comparing a continuous mean between two independent groups with simple sampling, use Welch's two-sample t-test by default (`scipy.stats.ttest_ind` with `equal_var=False`). Use a paired test only for verified pairs and keep the within-pair structure. For Welch and paired t-tests, use the test result's `confidence_interval(confidence_level=0.95)` for the mean difference. Report group counts, means, difference, test statistic and p-value. [SciPy Welch t-test](https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.stats.ttest_ind.html)
- If testing association between categorical variables for independent simple observations, use Pearson's chi-square on observed unweighted counts. Check expected counts. For a sparse 2×2 table, consider Fisher's exact test; flag sparse larger tables rather than overstating the result.
- If survey weights, clusters, strata or replicate weights matter, keep the descriptive estimates survey-weighted and report unweighted counts. Ordinary Welch or chi-square p-values on weighted counts are not design-based inference. Use a suitable design-aware method only when the design and implementation are available. Otherwise explain why significance cannot be estimated reliably.
- Use a 95% confidence interval and alpha 0.05 unless the user requests another level. State the test's significance at that level. Report the interval and margin of error for the effect estimate, such as a mean difference or a difference in proportions. For an omnibus test such as chi-square, report the overall p-value and give the interval and margin for an interpretable effect or planned contrast when available.
- Use the same weighted or unweighted basis for the effect, confidence interval, and margin of error. Use `critical value × SE` for a symmetric margin, equivalent to half the confidence interval width. For an asymmetric interval, report both distances from the estimate in one margin-of-error entry. Use the survey design for uncertainty on weighted estimates. If the required design information, assumptions, or effect interval are unavailable, state which result is unavailable and why. [CDC survey inference guidance](https://wwwn.cdc.gov/nchs/nhanes/tutorials/varianceestimation.aspx)
- Apply the general missingness, weight and denominator rules. Give the exact test, analysis base and exclusions in the collapsed method note.

References: [SciPy Welch t-test](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html), [SciPy chi-square](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.chi2_contingency.html), [survey design-based tests](https://faculty.washington.edu/tlumley/old-survey/html/svychisq.html).
